# Teacher's Day Message Card

A responsive Teacher's Day greeting webpage for Sir Randy Bello, with a rainbow-inspired professional design and an animated message reveal.

## Project files
- `index.html` — webpage structure and message
- `style.css` — layout, rainbow theme, responsive styles, and animations
- `script.js` — open/close message interaction
- `assets/teacher-photo.png` — the teacher photo supplied for this card

## How to run
1. Extract the ZIP file.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a web browser.

The fonts load from Google Fonts when an internet connection is available. A system serif/sans-serif fallback is included.

## Personalize
Edit the greeting and signature in `index.html`. You can change colors in the `:root` section of `style.css`.
